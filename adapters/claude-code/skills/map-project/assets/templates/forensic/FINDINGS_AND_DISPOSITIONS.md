## Keep, Rewrite, Delete, or Merge

- **Keep** only with evidence that the contour is current and necessary.
- **Rewrite** only when the owning mechanism cannot safely meet the target contract.
- **Delete** only after reachability, replacement, data, and rollback evidence are complete.
- **Merge** only when one owner can replace overlapping behavior without hiding differences.
